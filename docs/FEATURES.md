# Features

- Normal Space Station 14 human multiplayer behavior.
- Optional graphical agent client enabled only by `agent.bridge_port`.
- Loopback-only JSON Lines protocol v0 with bounded messages and queues.
- Tick-stamped observations of the attached player and interaction-reachable doors.
- Movement, door interaction, and local speech through ordinary client/server gameplay paths.
- Explicit accepted or rejected action results, duplicate detection, and stale-action rejection.
- Scripted M1 runner for a human-visible move, door, and speech proof.
